Salary Prediction Using Machine Learning

Linear Regression  ·  Python & Scikit-learn  ·  2024

1. Project Overview

This project demonstrates an end-to-end Machine Learning pipeline that predicts an employee's annual Salary from their Years of Experience. A Linear Regression model was trained using Python and Scikit-learn on a real-world dataset of 28 observations.

The project is structured to be beginner-friendly and submission-ready, covering every stage of a typical ML workflow: data loading, validation, training, evaluation, model persistence, and a command-line prediction interface.

3. Model Performance

The dataset was split 80 % training / 20 % test (random seed 42). A LinearRegression estimator from Scikit-learn was fitted on the training set and evaluated on the held-out test set. All metrics below are computed from actual predictions on unseen data.

0.9684 R² Score
$3,830 MAE
$4,837 RMSE
22 / 6 Train / Test samples

An R² of 0.97 means the model explains roughly 97 % of the variance in salaries — an excellent fit for a single-feature linear model.

4. Learned Model Equation

The fitted linear equation is:

Salary  =  9550.03 × YearsExperience  +  25613.67

Interpretation: each additional year of experience is associated with an estimated salary increase of $9,550. A candidate with zero experience would have a predicted baseline of $25,614.

7. How to Run

Step 1 — Install dependencies

pip install -r requirements.txt

Step 2 — Train the model

python src/train_model.py

Step 3 — Launch the CLI application

python app/app.py

At the prompt, enter a number (e.g. 5.0) and press Enter to see the predicted salary. Type quit to exit.
